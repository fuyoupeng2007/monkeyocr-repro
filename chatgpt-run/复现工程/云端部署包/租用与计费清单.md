# 租用与计费清单

## 平台选择

首选AutoDL，备选恒源云、矩池云。首选理由是AutoDL公开提供按量计费、关机停止GPU计费、按秒结算，并且当前官网公开展示RTX 3090 24GB约1.32元/小时。最终价格与空闲机器以创建实例页面为准。

## 创建实例时逐项核对

- 计费模式：按量计费
- GPU数量：1
- GPU型号：RTX 3090 24GB
- CPU内存：至少32GB
- 数据盘：免费容量不足时扩到100GB；扩容盘可能在关机后继续收费
- 镜像：PyTorch 2.5.1、Python 3.10、CUDA 12.4最优；相近CUDA开发镜像也可以
- 地区：选择网络延迟低且ModelScope下载稳定的国内节点
- 自动续费：关闭
- 充值：第一轮20元足够覆盖预计6–12小时的3090 GPU费并留少量余量；数据盘费用另计

## 时间预算

| 工作 | 预计计费时间 |
|---|---:|
| 首次创建、上传部署包 | 0.3–0.8小时 |
| 安装依赖、下载约数GB权重 | 1–3小时 |
| 5页冒烟测试与一次排错 | 1–2小时 |
| 100页正式推理与一次必要重跑 | 1–3小时 |
| 汇总、下载结果、留出异常余量 | 1–3小时 |
| 第一轮合计 | 6–12小时 |

按当前公开的1.32元/小时估算，GPU费约7.92–15.84元。建议先充值20元，不开月套餐。此处不含付费扩容数据盘，实际以控制台结算为准。

## 关机前检查

1. `outputs/`已经下载回本地；
2. 保存`verify_env.py`输出、安装日志、运行命令和耗时；
3. 权重无需反复下载时保留实例；长期不用时先制作镜像或下载必要文件，再释放；
4. 在控制台确认实例状态已经变成“关机”，并检查付费数据盘是否继续计费。
