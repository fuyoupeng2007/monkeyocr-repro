# MonkeyOCR 公开权重复现实验

## 1 结论与范围

本项目复现 MonkeyOCR 的公开权重推理和 OmniDocBench 历史版端到端评分链路。20页试跑与120页正式评测均完成，981页完整集按实验计划明确未运行。120页正式子集涵盖9类文档、中文和英文、单栏与多栏版式、文本、公式和表格标注。

正式120页中，MonkeyOCR 成功生成112页输出；其余8页在上游区域分析后向识别后端传入空提示列表并触发 `IndexError`。这8页统一以空Markdown交给官方评测器，作为完整遗漏计分，避免遗漏样本造成分数偏高。

## 2 版本与环境

| 组件 | 固定版本 |
| --- | --- |
| MonkeyOCR 源码 | `b5e94d3aed972e2e07e7d5c654a0dc588419f4b9` |
| OmniDocBench 评测 | `2757e3b8a1dc981eb8b7e94a5a56646891f67143` |
| OmniDocBench 数据 | `f5f559bddf50e36f7f9899d842d0006f13ce8afc` |
| 正式子集 | 120页，固定种子250605 |
| 硬件 | RTX 4090D 24GB |

模型运行峰值显存为17,960.7 MiB。112个成功页面的模型阶段累计640.82秒，平均5.72秒/页。该速度不含进程启动、可视化PDF导出和评测时间。

## 3 MonkeyOCR 评测结果

| 指标 | 论文 MonkeyOCR 3B 981页 EN | 本复现 120页 EN | 论文 MonkeyOCR 3B 981页 ZH | 本复现 120页 ZH |
| --- | ---: | ---: | ---: | ---: |
| Overall Edit 距离 | 0.140 | 0.184 | 0.297 | 0.229 |
| Text Edit 距离 | 0.058 | 0.096 | 0.185 | 0.114 |
| Formula Edit 距离 | 0.238 | 0.280 | 0.506 | 0.503 |
| Table TEDS | 80.2 | 81.8 | 77.7 | 84.1 |
| Table Edit 距离 | 0.170 | 0.166 | 0.253 | 0.179 |
| Reading Order Edit 距离 | 0.093 | 0.192 | 0.244 | 0.121 |

历史评测器为公式CDM导出配对JSON，不直接计算数值，报告不将其填成0或缺失成绩。某一页的文本匹配出现超时，官方评测器自动回退到简单匹配方法，已保留在运行日志。

与论文数值不同并不单独说明模型退化。主要原因是本项目使用固定120页分层子集而论文汇总981页；公开权重和推理代码版本与作者内部运行可能不同；GPU、后端、输出规范化与模型异常处理也会改变最终端到端分数。复现中对8个异常页完整计分，尤其会影响`note`类页面。

## 4 裁框消融

从MonkeyOCR的`middle.json`提取检测框，选择与冻结GT相交但GT覆盖率不足的50个疑似错裁区域。全部使用同一公开权重、同一任务提示、同一GT，比较原框、四边各扩2%、四边各扩5%。区域级归一化编辑距离仅用于诊断裁框边界，不能替代OmniDocBench端到端分数。

| 设置 | 平均区域编辑距离 | 改善 | 持平 | 退化 |
| --- | ---: | ---: | ---: | ---: |
| 原框 | 0.6064 | - | - | - |
| 扩2% | 0.5813 | 23 | 18 | 9 |
| 扩5% | 0.5741 | 33 | 10 | 7 |

扩5%在该疑似错裁样本中平均改善0.0323，优于扩2%的0.0251。文本区域改善最稳定，扩5%有29/42改善、6/42退化。表格候选只有7个，扩2%反而有4/7退化，扩5%改善4/7；公式候选只有1个且三种设置持平。因此该实验支持“轻度扩框通常有帮助”的条件性结论，不能推广为所有区域均应扩框。

## 5 错误分析与下一步

已整理15个可回查案例目录，每例含原图、真值摘录、模型输出摘录、评分证据和原因判断。8例为漏检或上游异常；其余按文本、公式、表格和阅读顺序的官方错误值选择。下一步应在区域分析后加入空区域保护，针对高风险小框引入基于置信度或边界留白的自适应扩框，并把扩框前后与端到端阅读顺序的关系单独验证。

## 6 MinerU 对照

MinerU 0.9.3 独立环境、同一120页输入与同一官方评测器的结果将在运行完成后写入本节。由于该历史CLI只接收PDF，源图以不改变页面内容的单页PDF封装后输入，这一差异将作为比较限制明确报告。
