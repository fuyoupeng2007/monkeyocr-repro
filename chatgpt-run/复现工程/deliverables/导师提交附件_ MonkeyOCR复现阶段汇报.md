# MonkeyOCR公开权重复现实验阶段汇报

尊敬的老师：

本阶段完成了MonkeyOCR公开权重的可复跑评测链路、裁框消融和错误分析。实验重点是验证公开模型在固定历史版OmniDocBench上的可解释表现，而非进行高成本从头训练。MinerU同口径对照已实际运行80页；由于GPU可用算力和账户余额中断，剩余39页未运行，以下不将其作为完整120页结果报告。

## 2 MonkeyOCR正式复现

20页试跑完成后运行120页正式集。112页成功生成输出，8页在上游区域分析后传入空提示列表触发异常；8页均按空预测计入官方分数。

| 指标 | 英文 | 中文 |
|---|---:|---:|
| 整体编辑距离 | 0.184 | 0.229 |
| 文本编辑距离 | 0.096 | 0.114 |
| 展示公式编辑距离 | 0.280 | 0.503 |
| 表格TEDS | 81.8 | 84.1 |
| 表格编辑距离 | 0.166 | 0.179 |
| 阅读顺序编辑距离 | 0.192 | 0.121 |

成功页面模型阶段平均5.72秒/页，峰值显存17,960.7 MiB。历史评测器仅导出公式CDM配对JSON，未直接计算CDM数值，故不以空值替代分数。

论文981页MonkeyOCR-3B的整体编辑距离为英文0.140、中文0.297。本复现实验的120页构成、公开代码与作者内部环境不同，且完整计入8个异常页，数值不应当被解释为论文结果的直接替代；其价值在于链路可复跑、差异可定位。

## 3 裁框消融

从模型`middle.json`选择50个与GT相交但覆盖不足的疑似错裁区域，保持模型、提示和GT不变，仅比较原框、四边扩2%和扩5%。区域级编辑距离从0.6064降至0.5813和0.5741；扩5%改善33例、持平10例、退化7例。文本区域改善最稳定；表格候选较少且扩2%存在退化，说明固定扩框不是普遍规则，应改为基于类别、置信度和边界留白的自适应策略。

## 4 错误分析与MinerU状态

已整理15个可回查案例，包含原图、真值、模型输出、评分证据和原因判断。8例为漏检或空区域异常，其他案例覆盖文本、公式、表格和阅读顺序。

MinerU 0.9.3使用独立环境和同一历史评测器。实际完成80页推理；剩余39页因GPU算力和余额不足未运行。因此MinerU结果只作为80页阶段性观察，不能与MonkeyOCR120页正式总分作严格排名。后续如恢复算力，将在相同页ID上补齐39页后重新计算完整比较。
