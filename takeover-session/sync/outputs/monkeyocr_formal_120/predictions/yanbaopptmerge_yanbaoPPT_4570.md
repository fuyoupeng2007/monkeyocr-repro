# 陈忠实  

可达。村南有山，檀枋浮华，信息至此皆无，虽有电视，只闻其声，不见具形。

巩原上青草，岁岁枯荣，乃有思焉。忠实好文学，慕赵树理、杜鹏程，其为难子时，诵”田寡妇看瓜“，摹之，传之，师生赞叹。

柳青居然罪人，忠实惧，焚所作文，窃曰：“吾母谓吾不逢风雨，其是之谓乎？呜呼，文学有罪乎？吾不得申乎？”然有新气象，忠实乃为文，谓往日极左为非，县里见此文，谓忠实曰：“竖子为此文，触大忌，死矣。”乡里揣揣，然终无事。

后为小吏，凡二十载，遍乡里，三十里皆识真人。

官，以文为职。

“关中，人文盛地也，焉得无鸿篇巨制，诸子努力。”乃有贾平凹，乃有陈忠实，文学先锋，荷甲趋阵，为三秦文学突陈夺寨，于斯乎？”乃摒喊市，居乡里，旧居不堪，雨则无庇身处，乃寄亲戚家。

巩白鹿乡里烈妇传甚夥，太息曰：“悲哉，白鹿妇人，以一生悲忍，成县志一行之文，血泪何其殷也。吾不为之文，谁为之文？”此木成。”呜呼，此树今如盖也。

饮，问：“陈生浸润史志，非文学家事，何为？”忠实曰：“欲志白鹿原，吾百年后，当以此书为枕。”“其年，丙寅年（1986）也。”  

后，饮，问：“陈生浸润史志，非文学家事，何为？”思买曰：“欲志曰唐原，吾自年后者，当以此书为枕。”其年，丙寅年1986。

史官。后之记史，或面目可憎，或忌讳颇盛，或全无实情，书中人物，全无表情，惟多定论，阅之可笑。小说，实则史录；《人生》之高生，若史记之淮阴侯；《白鹿原》之黑子，若吴越春之伍子胥。人皆有面目，事皆有原委，阅之，平时无一事无一人不在其中。
